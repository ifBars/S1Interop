# S1Interop

Write Schedule I mods in ordinary C# and build for Mono and IL2CPP from the same source. S1Interop adapts supported runtime differences using your local game assemblies, so game access doesn't depend on a manually maintained wrapper library.

It's still experimental. Check [what works and what's missing](docs/SOURCE_COMPILER.md) before relying on it for your mod.

## Get started

[Install S1Interop](docs/docfx/articles/getting-started.md), then [build your first mod](docs/docfx/articles/first-mod.md). Already have a mod? [Bring it over](docs/docfx/articles/compiler-adoption.md).
