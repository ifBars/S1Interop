| [Real-mod evidence](real-mod-evidence.md) | You need to know which real mods have tested the current claims. |
| [Test a source build](source-builds.md) | You are developing or testing an unpublished package. |
| [Testing](testing.md) | You want the maintainer-side test lanes and CI-equivalent commands. |
| [Publishing docs](publishing-docs.md) | You are building or publishing the DocFX site. |
| [Contributing](contributing.md) | You are changing the repo and need the local workflow. |
